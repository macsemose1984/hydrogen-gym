# هايدروجين جم — Hydrogen Gym 🏋️

نظام إدارة نادي رياضي متكامل **سطح مكتب** بواجهة عربية RTL كاملة، مبني بـ Python + PySide6 (Qt).

## المزايا
الاتصال بجهاز البصمه
تنبيه عند البصمه في حاله انتهاء الاشتراك 
- **تسجيل دخول** (المستخدم الافتراضي: `admin` / كلمة المرور: `admin123`)
- **لوحة تحكم** بالإحصائيات (أعضاء، حضور اليوم، إيرادات الشهر، اشتراكات تنتهي قريباً)
- **الأعضاء**: إضافة / تعديل / حذف / بحث فوري (اسم، هاتف، كود) + رقم بصمة
- **خطط العضوية**: خطط بالمدة والسعر والجلسات
- **الاشتراكات**: اشتراك / تجديد مع تواريخ تلقائية وحالة نشط/منتهي
- **المدفوعات**: تسجيل دفعات (نقدي/بطاقة/تحويل) مع رقم مرجع
- **الحضور**: تسجيل دخول/خروج يومي + محرك بحث
- **واتساب 💬**: إرسال رسائل عبر **واتساب ويب** (يفتح `wa.me` تلقائياً بجملة جاهزة) — فردي أو جماعي أو لمن تنتهي اشتراكاتهم قريباً، مع قوالب (ترحيب، تجديد، فاتورة، عرض)
- **التقارير**: تقرير حضور / مالي / أعضاء مع تصدير PDF (يفتح في المتصفح للطباعة)
- **إعدادات**: اسم النادي، العملة، واتساب، تبديل اللغة عربي/إنجليزي، وتبديل المظهر **داكن/فاتح** 🌙

## التشغيل
```bash
pip install -r requirements.txt
python main.py
```

### بيانات تجريبية (اختياري)
```bash
python seed_demo.py
```

## البنية
```
hydrogen-gym/
├── main.py                 # نقطة التشغيل
├── seed_demo.py            # بيانات تجريبية
└── app/
    ├── database.py         # SQLite + مخطط الجداول
    ├── i18n.py             # ترجمة عربي/إنجليزي
    ├── whatsapp.py         # روابط wa.me + قوالب الرسائل
    ├── reports.py          # توليد تقارير HTML/PDF
    └── gui/                # واجهة PySide6
        ├── login.py, main_window.py
        ├── pages/          # لوحة التحكم، الأعضاء، الخطط، الاشتراكات، الدفعات، الحضور، التقارير، واتساب، الإعدادات
        └── dialogs/        # نوافذ إضافة/تعديل
```

## ملاحظة واتساب
للإرسال التلقائي يجب أن يكون **واتساب ويب** مسجلاً دخوله في المتصفح (web.whatsapp.com). البرنامج يفتح رابط `wa.me/رقم?text=رسالة` ويتم الإرسال تلقائياً عند فتح الصفحة.
